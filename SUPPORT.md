# Getting support

- For reproducible bugs, use the [bug report form](https://github.com/Deepworkpalestine/night-of-assassins/issues/new?template=bug_report.yml).
- For feature ideas, use the [feature request form](https://github.com/Deepworkpalestine/night-of-assassins/issues/new?template=feature_request.yml).
- For questions about contributing, read [CONTRIBUTING.md](CONTRIBUTING.md).
- For security vulnerabilities, follow [SECURITY.md](SECURITY.md) and do not post details publicly.

When asking for help, include the app version or commit, Flutter version, Android version/device (if relevant), expected behavior, and the steps needed to reproduce the problem. Remove personal information and secrets from logs before sharing them.
