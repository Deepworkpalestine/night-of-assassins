# Security Policy

## Supported versions

The project is currently in active development and has not published a stable tagged release. Security fixes are applied to the default branch when practical. Once releases are published, this section will identify supported versions.

## Reporting a vulnerability

Please do **not** report exploitable security vulnerabilities in public issues or pull requests.

Use GitHub's private vulnerability reporting flow for this repository, if it is enabled:

https://github.com/Deepworkpalestine/night-of-assassins/security/advisories/new

If private reporting is unavailable, contact the maintainer privately through the [GitHub profile](https://github.com/Deepworkpalestine). Include the affected version or commit, impact, reproduction steps, and any suggested mitigation. Do not include secrets or other people's personal data.

## Scope

Reports may include vulnerabilities in application code, dependency usage, release automation, or build configuration. Please report only issues in systems and code that you are authorized to test.
