# Code of Conduct

## Our commitment

The Night of Assassins project aims to provide a welcoming, respectful, and harassment-free environment for everyone who participates in project discussions, issue reports, code reviews, and contributions.

## Expected behavior

- Be respectful, constructive, and considerate.
- Focus criticism on ideas and code, not people.
- Accept differing opinions and experience levels.
- Provide useful context when reporting problems.
- Respect other contributors' time and privacy.
- Give credit for work and respect licenses and attribution requirements.

## Unacceptable behavior

- Harassment, threats, discrimination, or personal attacks.
- Trolling, deliberate disruption, or insulting language.
- Publishing another person's private information without permission.
- Submitting malicious code, spam, or knowingly misleading reports.
- Using project spaces to promote unlawful or abusive activity.

## Enforcement

Project maintainers may edit or remove contributions, close discussions, or restrict participation when behavior violates this Code of Conduct. Reports should be sent privately to the project maintainer through the contact options on the [GitHub profile](https://github.com/Deepworkpalestine). Please include links or context needed to understand the report. Maintainers will handle reports as confidentially as reasonably possible.

This Code of Conduct applies to all project spaces, including issues, pull requests, reviews, and other project communication.
